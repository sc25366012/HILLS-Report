# HILLS Daily Report — Streamlit MVP

## ฟังก์ชัน
- ถ่ายรูปด้วยกล้องมือถือ หรืออัปโหลดรูปต้นฉบับ
- กรอกข้อมูลรายงาน HILLS ด้วยตนเอง
- บันทึกยอดขายรายชั่วโมงและข้อมูลพนักงาน
- เก็บข้อมูลใน SQLite
- ค้นหาประวัติและดูรูปต้นฉบับ
- ส่งออก Excel 3 ชีต: Daily Summary, Hourly Sales, Staff
- ส่งออก ZIP ที่มี Excel และรูปต้นฉบับ

## เปิดใช้งานในเครื่อง
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux:
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Deploy เพื่อให้คนอื่นทดลอง
1. อัปโหลดไฟล์ทั้งหมดขึ้น GitHub
2. เข้า https://share.streamlit.io/ แล้วเลือก repository
3. ตั้ง Main file path เป็น `app.py`
4. Deploy

## ข้อจำกัดสำคัญ
แอปตัวอย่างนี้ใช้ SQLite เป็นที่เก็บข้อมูลในโฟลเดอร์ `data/` ซึ่งเหมาะกับการทดลองในเครื่อง
บน Streamlit Community Cloud พื้นที่ไฟล์ในเครื่องไม่ใช่ฐานข้อมูลถาวร ข้อมูลอาจสูญหายเมื่อแอปถูกรีบูต/สร้างใหม่
หากต้องการให้หลายคนใช้และข้อมูลไม่หาย ควรเปลี่ยนไปใช้ Supabase หรือ PostgreSQL ก่อนใช้งานจริง

## หมายเหตุ
ช่องข้อมูลสร้างจากหมวดข้อมูล HILLS ที่คุยกันไว้ ได้แก่ วันที่ สภาพอากาศ อุณหภูมิ ผู้รับผิดชอบ เป้าหมาย ยอดคาดการณ์ ยอดจริง จำนวนลูกค้า หมายเหตุ ยอดขายรายชั่วโมง และตารางพนักงาน
ควรตรวจเทียบชื่อช่องกับแบบฟอร์มต้นฉบับของร้านอีกครั้งก่อนใช้งานจริง
